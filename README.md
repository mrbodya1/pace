# PACE

PACE — мобильное приложение для тренировок и отслеживания спортивной активности. Проект создаётся на Flutter и сейчас находится в активной разработке.

Интерфейс выполнен в тёмной спортивной стилистике. Основной акцент текущей версии — GPS-трекер и игровая система прогресса атлета.

## Возможности текущей версии

- **GPS-трекер:** запись тренировки с использованием геолокации устройства.
- **Показатели тренировки:** дистанция, продолжительность, текущая скорость и темп.
- **Управление записью:** старт, пауза, продолжение и завершение тренировки.
- **Фильтрация GPS:** отбрасываются неточные координаты и неправдоподобные скачки скорости.
- **Виды активности:** бег, ходьба и велосипед.
- **История и статистика:** завершённые тренировки отображаются в истории текущего сеанса приложения.
- **Игровой прогресс:** начисление XP, уровни атлета и индикатор прогресса.

Тренировка добавляется в историю, если её дистанция составляет не менее 50 метров. XP начисляется из расчёта 100 XP за километр.

## Технологии

- [Flutter](https://flutter.dev/) — кроссплатформенная разработка.
- [Dart](https://dart.dev/) — язык программирования.
- [geolocator](https://pub.dev/packages/geolocator) — получение координат и GPS-данных.
- Material 3 — основа интерфейса.

## Запуск проекта

### Требования

- установленный Flutter SDK;
- Dart SDK версии, соответствующей ограничению проекта в `pubspec.yaml` (Dart `^3.13.5`);
- Android Studio и Android SDK для запуска на Android;
- эмулятор Android или физическое устройство.

### Установка

Клонируйте репозиторий:

```bash
git clone https://github.com/mrbodya1/pace.git
cd pace
```

Установите зависимости:

```bash
flutter pub get
```

Проверьте окружение:

```bash
flutter doctor
```

Запустите приложение:

```bash
flutter run
```

Для записи тренировок разрешите приложению доступ к геолокации и включите службы определения местоположения на устройстве.

## Что ещё предстоит реализовать

Следующие возможности не следует считать готовыми функциями текущей версии:

- постоянное сохранение истории тренировок и прогресса между запусками приложения;
- надёжная фоновая запись GPS при свёрнутом приложении и заблокированном экране;
- отображение маршрута на карте;
- полноценная система профилей и пользовательских настроек;
- работающая система уведомлений;
- серверная синхронизация данных между устройствами.
