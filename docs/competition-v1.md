# PACE — условия соревнований и автоматический зачёт

12 ноября 2026. Продолжение рабочего сообщества. Код, сервер и APK обновлены; проверка на телефоне отложена.

## Форматы и условия

Четыре суммарных зачёта: километры, время движения, набор высоты, количество тренировок. Больше результат — выше место. У каждого соревнования один формат, выбранный спорт (либо все виды), срок, открытый или клубный доступ.

Необязательные условия каждой тренировки: минимальная дистанция, время, набор высоты; границы среднего темпа (мин:сек/км); мужская/женская категория либо все участники. Категория берётся из сохранённого расчёта тренировки, а не из текущего профиля. Темп = активное время / дистанция. Это фильтры доступных показателей, свободный текст описания автоматически не интерпретируется.

Условия версии1 проверяет и сохраняет сервер при публикации; API редактирования опубликованных правил нет. Новый старт без правил создать нельзя. Старые события без правил не получают выдуманный зачёт.

Предложение о покрытии пульса80% и пропусках до2мин **не согласовано**: пользователь уточнил причины пропусков. Объяснены потеря контакта датчика/связи и начало записи до получения пульса. Обычная частота измерения и паузы не должны смешиваться с потерей сигнала. Обязательный пульс в этом этапе выключен; попытка включить его через API отклоняется. Garmin-пульс в личной истории сохраняется по прежним правилам. Критерии качества и активные интервалы потребуют отдельного согласования.

## Автоматический расчёт

- Участник вступил в соревнование; для закрытого зачёта сохраняет членство в клубе. Прежние уровни2/5/10 и роль владельца действуют.
- Тренировка началась после вступления и внутри срока, полностью завершилась до окончания срока и не находится в будущем. Время сравнивается в UTC. Задним числом тренировки до вступления не добавляются.
- Сохранены точные начало и окончание, положительные дистанция/активное время, непротиворечивые измерения. Совпадают спорт, категория и числовые условия.
- Считается вся тренировка целиком, отрезок за границей срока не обрезается. При повторной синхронизации сумма пересчитывается, а не прибавляется снова. Дубли sessionId не учитываются.
- Километры считаются с точностью метра, набор — метра, время — секунды. Равные результаты имеют общее место:1,1,3. Нет придуманного преимущества по имени или порядку поступления.
- Выход удаляет результат участника. Повторное вступление начинает новый срок участия и не возвращает старые тренировки. Выход из клуба удаляет закрытое участие и соответствующий результат.

Рабочая история и обычный XP не изменяются из-за отказа в соревновательном зачёте. Новых бонусов XP и наград за соревнования не вводилось. Быстрейшее прохождение конкретной дистанции — отдельный будущий формат, не подменяется средним темпом всей тренировки.

## Время окончания и совместимость

Workout получает необязательное endedAt, сохраняемое в JSON и при начислении наград. Новые записи PACE фиксируют фактическое окончание с паузами. Garmin использует измеренное total_elapsed_time из FIT; активная длительность остаётся total_timer_time. Если измеренного elapsed нет, окончание не придумывается. Старые записи без точного окончания остаются в истории, но не участвуют в новом зачёте; в личных причинах отображается отсутствие времени.

Новые startedAt/endedAt для зачёта записываются с часовым поясом. Формат старого date/startedAt без endedAt сохранён, чтобы не менять идентификаторы legacy-синхронизации, основанные на JSON-хеше. Для участия нужны обновлённые версии приложения; на старых сборках новых полей ещё нет.

## Хранение, таблица и приватность

Миграция1794474000: JSON scoring у событий, joinedAt у членства, закрытая pace_competition_scores с уникальным (event,user) и индексом ранжирования. При успешном PUT прогресса в той же транзакции пересчитывается производный результат участника. Вступление создаёт начальное состояние, выход его удаляет. Постоянных расчётных процессов и задач не добавляется.

POST /api/pace/community/action с action=results возвращает по25 строк. Используется прежний точный HTTPS-маршрут с лимитом8KiB; новые внешние пути не открываются. Прямой CRUD результатов закрыт. Строки содержат имя, результат, число тренировок, место, признак «ты» и непрозрачный ID строки для удаления дублей пагинации. Нет email, account ID, маршрутов, пульсовой записи или идентификатора Garmin. Сводка причин отказа доступна только владельцу своей строки. Для закрытого события таблица доступна членам клуба; в описании до вступления показано, какие сведения будут видны в таблице.

Результаты отражают синхронизированную историю; поздняя синхронизация подходящей тренировки может обновить сумму после конца события. Отдельная окончательная фиксация победителей, окно поздних загрузок и призы ещё не задавались. Таблица не выдаётся за неизменяемый итоговый протокол.

**Ограничение достоверности:** сервер считает зачёт сам, но использует нынешний клиентский снимок тренировок/XP. Это не защита от намеренной подмены данных, пола или времени. Для защищённых соревнований потребуется серверная проверка происхождения тренировок и пульса. Не объявлять этот этап античитом или проверенными официальными результатами.
