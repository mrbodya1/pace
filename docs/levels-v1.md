# Уровни и шкала XP v1

10 ноября 2026. Пользователь выбрал этап «Уровни и шкала XP». Существующие пороги 1–10 сохранены. Продолжение после 10-го следует последним шагам прежней шкалы: переход к 11-му требовал 20 000 XP, затем цена каждого перехода возрастает на 3 000 XP. Новые пороги — реализация этого продолжения; отдельную новую систему рангов/наград пользователь не утверждал.

Один общий уровень для всех видов спорта. Смена специализации не обнуляет уровень. XP тренировок, обычных достижений и рекордов идут в тот же общий баланс. За повышение уровня отдельный XP не начисляется. Награды и формулы тренировок не меняются.

Для уровня L ≥ 10 и k = L − 10:

`порог(L) = 65 000 + 20 000 × k + 1 500 × k × (k − 1)`.

## Поведение приложения

- Раньше при 85 000 XP приложение продолжало показывать уровень 10 и «0 XP до уровня 11». Теперь при 85 000 XP показывается уровень 11, до 12-го остаётся 23 000 XP. При 108 000 XP — уровень 12.
- Большая награда может сразу пересечь несколько уровней; остаток XP учитывается внутри фактического нового уровня. Например, 165 000 XP — уровень 14, 2 000 XP внутри него и ещё 30 000 XP до 15-го.
- На главной добавлена кнопка «Шкала уровней». Экран показывает текущее состояние, первые десять порогов и ближайшие следующие уровни, выделяет достигнутые/текущий. Для крупного шрифта используется существующий доступный линейный индикатор вместо кольца.
- Уровень вычисляется через XpProgress из общего XP. В серверном снимке и локальной истории новый уровень не записывается, миграция не нужна. Обновление шкалы не пересчитывает и не меняет старые XP. Приход XP с сервера использует те же правила отображения.
- Большой баланс обрабатывается экспоненциальным поиском границы и бинарным поиском уровня; нет перебора миллионов уровней или большого массива порогов. На экране строится только ограниченное число строк вокруг текущего уровня и первые десять.

## Проверки

Добавлены проверки сохранения всех прежних порогов, известных новых значений, непрерывности переходов до 500-го уровня, пересечения нескольких уровней, половины прогресса внутри уровня, отрицательного некорректного входа и максимального целого XP, поддерживаемого серверным JSON. UI проверяется на 320 px с обычным и двойным шрифтом, переход на экран/назад не меняет сохранённый XP.

Телефон, рабочий сервер и данные аккаунта этим этапом не менялись. Проверка на устройстве остаётся отложенной по просьбе пользователя. Новая шкала не требует перезапуска сервера; для ранее добавленной серверной синхронизации всё ещё требуется обновление по account-progress.md.
