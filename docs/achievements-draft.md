# Достижения и личные рекорды PACE — текущая простая схема

9 ноября 2026. Схема уточнена пользователем после первого слишком сложного черновика. Код и формулы XP не менялись. Один общий уровень пользователя; достижения по видам спорта независимы. Смена специализации прогресс не обнуляет.


Полная рабочая версия v1 с точными порогами и XP: [achievements-v1.md](achievements-v1.md). Числовой каталог: achievements-v1.json. Ниже сохранено описание сокращённой схемы до распределения XP.

Подтверждено пользователем 10 ноября 2026: первый результат — отдельные 50 XP один раз; каждое последующее улучшение времени на каждой дистанции и в каждом виде спорта приносит 100 XP. Ограничения числа наград нет.

## Убрано

- Количество активных дней.
- Календарные серии недель и месяцев, награды за регулярность.
- Длительность одной тренировки как отдельное достижение.
- Фиксированные пороги темпа и скорости.
- Отдельные награды за суммарные 5/10 улучшений рекордов.

Накопленные километры возвращены пользователем: и по видам, и общий километраж. Рекомендация помощника оставить регулярность не принята и в рабочую схему не включена.

## Правила и оставшиеся вопросы

- Размеры дополнительных XP подтверждены пользователем 10 ноября 2026 с заменой рекордного правила на постоянные 100 XP за каждое улучшение; полная таблица — achievements-v1.md.
- Удаление/исправление и минимальная зачётная активность. Пересечённые новые ступени суммируются; старая история засчитывается без пересчёта XP.
- Качество измерений для рекордов: бассейн/открытая вода отдельно; короткие отрезки требуют достаточной точности; паузы не должны создавать скоростной рекорд.
- Время/точность GPS-точек и границы пауз добавлены. GPS-рекорды реализованы, правила качества описаны в achievements-v1.md; бассейн пока не поддерживается.
- Серверное хранение истории, XP и достижений: сейчас серверный только профиль, тренировки и XP локальные.

311 обычных достижений реализованы локально по утверждённой таблице v1. Подключены GPS-рекорды 67 дистанций; каждое улучшение +100 XP без лимита. В GitHub эти изменения пока не опубликованы.
