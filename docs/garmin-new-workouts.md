## Что работает

- Личный Garmin-ключ подтверждён, привязан приватно к одному аккаунту PACE, выбранному пользователем по почте. Email/ID/ключ в этот документ не включены.
- Неизменяемая граница импорта: 12 ноября2026, 13:30:29 по Екатеринбургу (08:30:29.774666UTC). В приватном import-config.json. Повторный запуск не сдвигает границу.
- Локальный сборщик проверяет новые записи каждые120секунд; первый проход добавил0, пропустил0. Приватная очередь пока пустая. Старые FIT не скачивались.
- Garmin Personal API фильтрует список по календарной дате; сборщик дополнительно строго проверяет startTimeGMT и начало FIT относительно UTC-границы. При будущих опросах в ответ списка могут входить более ранние записи того же дня: они отсеиваются до скачивания FIT и не импортируются. Полная старая история не запрашивается.
- Авторизованный GET /api/pace/garmin отдаёт очередь только привязанному PACE ID. Другие аккаунты получают available:false без данных. Нет произвольного параметра владельца/пути/URL.
- В PACE обычная кнопка Прогресс→Обновить сначала синхронизирует прогресс, затем добавляет новые Garmin-записи через прежние движки XP/достижений/рекордов и отправляет результат в аккаунт.
- Сохраняются источник, внешнийID, время импорта, хеш FIT и временной ряд пульса. В деталях тренировки видны Garmin и наличие/отсутствие записи пульса. Это не график пульса и не оценка качества для будущих соревнований.
- Пропуски GPS и события остановки разрывают зачётные сегменты. Точность GPS не выдумывается: если Garmin её не передал, соответствующие GPS-рекорды не присваиваются.
- Повторные ID не скачиваются повторно и не добавляют XP повторно. Если похожая тренировка уже записана самим PACE (спорт/начало/длительность/дистанция), импорт удерживается как возможный дубль. Активный черновик записи PACE не удаляется импортом.

## Устройство и вечерняя проверка

1. Установить свежий debug APK поверх текущего приложения: D:/Applications/PACE/Project/build/app/outputs/flutter-apk/app-debug.apk . Не удалять приложение ради обновления.
2. Записать новую тренировку на Garmin и синхронизировать устройство с Garmin Connect.
3. Домашний Windows-PC должен быть включён и не спать. Подождать около2минут.
4. Войти в свой PACE-аккаунт и нажать Прогресс→Обновить. Проверить появление одной тренировки и наличие пульса в её деталях. Повторное Обновить не должно удваивать запись/XP.

Реальная вечерняя тренировка ещё не записана: её end-to-end импорт/пульс предстоит проверить после записи. Новый APK собран, но установка/запуск на устройстве сейчас не выполнялись.

## Запуск и остановка сборщика

Сейчас запущен отдельный скрытый процесс, без новой Windows-задачи и без изменения автозапуска. После перезагрузки ПК его нужно запустить снова:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File D:\Applications\PACE\Project\server\garmin\start-personal-watcher.ps1
```

Однократный запрос вместо фонового режима: server/garmin/pull-new.ps1 . PID и очищенные от приватных подробностей журналы находятся внеGit: D:/Applications/PACE/Runtime/Garmin. Для остановки использовать текущий PID из watcher.pid только после проверки имени/path/command line процесса; не завершать всеPython-процессы подряд. Ключ защищён WindowsDPAPI и ACL, токен в работающем сборщике переиспользуется в памяти до23часов, на диск не сохраняется.

SDK: официальный garmin-fit-sdk21.221.0 в отдельном venv внутри Runtime/Garmin, wheel проверен SHA256 поPyPI. Ни ключ, ни очередь, ни логи, ни venv не попадают в Git или APK.

## Оставшиеся ограничения

Это личное подключение одного аккаунта, не общедоступный GarminOAuth для других пользователей. Не все виды Garmin сопоставлены с PACE; неподдерживаемые/ручные/мультиспортивные записи удерживаются без ложного преобразования. Бассейн не добавлен; для плавания принимается только открытая вода. Размер одного FIT до20MiB, очередь до200новых записей/30MiB; очистка после длительного использования требует отдельного решения и не удаляет данные автоматически. Правила достаточного покрытия пульса для соревнований пока не согласованы. Расчёт XP остаётся клиентским, это не серверная античит-система. Не использовать старую версию PACE для сохранения Garmin-метаданных: новыйAPK содержит необходимые поля; приватная исходная очередь остаётся копией записи.

Исходники/документация этого Garmin-этапа пока локальные, GitHub отдельно не обновлялся. Рабочая история/XP пока не менялись: импортировано0активностей.
