# PACE — Garmin по запросу приложения

12 ноября 2026. Этот режим заменяет прежний постоянный опрос.

## Поведение

- При открытии PACE с полноценной сессией выполняется одна проверка Garmin.
- При возвращении из фона автоматическая проверка допускается не чаще раза в 5 минут.
- «Прогресс → Обновить» запрашивает проверку вручную. Автоматический интервал при этом обходится, но на сервере остаётся защита от дублирующих запусков и минимум 10 секунд после успешного запроса.
- Обычное сохранение/завершение тренировки и синхронизация прогресса сами по себе не запускают Garmin.
- Таймера постоянного опроса нет ни в приложении, ни в серверном сборщике. Проверенный прежний --watch-процесс остановлен, по финальной проверке collect_personal.py процессов 0. Новые Windows-задачи не создавались.
- Приложение открывается сразу: обновление асинхронно. Во время одного запроса клиент кратко проверяет только готовность приватной очереди; это не повторные обращения к Garmin. При уходе приложения из активного состояния клиент прекращает ожидание/опрос статуса. Уже запущенная короткая серверная задача может закончиться после закрытия приложения, но не повторяется самостоятельно.

## Серверная схема

1. Авторизованный клиент читает GET /api/pace/garmin; чужому аккаунту данные недоступны.
2. Только владелец привязки может вызвать POST /api/pace/garmin/refresh с boolean force.
3. PocketBase вызывает фиксированный PowerShell-launcher без передаваемых пользователем путей/команд. Он быстро запускает один скрытый Python-процесс и возвращает running/ready.
4. Именованный mutex, статус и файловая блокировка исключают дублирующие задания; законченные автоматические проверки кэшируются на 5 минут, ручные на 10 секунд.
5. Python выполняет один проход, сохраняет ready/error и завершается. Новые FIT загружаются только после неизменённой границы: 12 ноября 2026, 13:30:29 Екатеринбург. Максимальный рабочий проход ограничен временным бюджетом; большие очереди продолжаются при следующем запросе.
6. Клиент импортирует записи через прежние движки XP/ачивок/рекордов, сохраняя источник, пульс, дедупликацию и активный черновик.

Ключ по-прежнему Windows DPAPI вне Git; токен и заголовки не передаются в PACE/APK. Доступ к Garmin идёт только с домашнего сервера. Основные PocketBase/Caddy должны работать; отдельный постоянный Garmin-сборщик после перезапуска компьютера запускать не нужно.

## Использование

Обновить APK поверх установленного приложения: D:/Applications/PACE/Project/build/app/outputs/flutter-apk/app-debug.apk . После новой тренировки синхронизировать Garmin с Connect, затем открыть PACE или нажать «Прогресс → Обновить». Ждать фонового двухминутного расписания больше не нужно. Домашний сервер должен быть включён; первоначальный реальный импорт будет проверен на новой вечерней тренировке.

Старые инструкции start-personal-watcher.ps1 теперь являются совместимой обёрткой одного ручного запроса; бесконечного --watch режима в Python больше нет. Приватная привязка владельца/cutoff/очередь сохранены. Старые тренировки не импортировались. Документы и код этого Garmin-этапа пока локальные, GitHub отдельно не обновлялся.
